# Example screens

These are actual companion screens from the development installation, selected to exclude account names, conversations, personal libraries, photos and device identifiers. They illustrate the interface, not a guarantee that a new installation is configured or connected. Some installed labels still say Pixel; the [compatibility guide](COMPATIBILITY.md) explains the modern Android phone requirements.
